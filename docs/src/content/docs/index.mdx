## Manage every Supabase account from one CLI

The Supabase CLI holds one login at a time. If you juggle a personal org, several clients and a work account, supawho ends the `supabase logout → login → paste token` routine: save each **Supabase account** once, then switch by name, on **macOS, Linux or Windows**, from a single dependency-free binary.

## Switch accounts in three commands

```bash
supawho add          # save an account once: name + token (hidden input)
supawho use work     # switch the Supabase CLI to it
supawho whoami       # forgot which is which? map them all
```
